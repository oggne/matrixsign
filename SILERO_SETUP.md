# Настройка Silero TTS (Оффлайн озвучка)

Для работы оффлайн озвучки требуются модели Silero TTS в формате ONNX. Из-за большого размера (~50-100 МБ каждая) они не включены в исходный код.

## 1. Скачивание моделей

Вам понадобятся модели версии V4 (или совместимые V3/V5) в формате `.onnx`.

**Официальный репозиторий:** [snakers4/silero-models](https://github.com/snakers4/silero-models)

### Прямые ссылки (примеры):
*   **Русский язык (ru_v4.onnx):** [Скачать](https://models.silero.ai/models/tts/ru/v4_ru.onnx)
*   **Английский язык (en_v3.onnx):** [Скачать](https://models.silero.ai/models/tts/en/v3_en.onnx)

## 2. Размещение файлов

1.  Создайте папку `silero` внутри `app/src/main/assets/`, если она ещё не существует.
    *   Полный путь: `app/src/main/assets/silero/`
2.  Скопируйте скачанные файлы `.onnx` в эту папку.
3.  Переименуйте файлы (для соответствия коду), если они отличаются:
    *   `ru_v4.onnx` -> `ru_v4.onnx`
    *   `en_v3.onnx` -> `en_v3.onnx`

## 3. Проверка

1.  Пересоберите и запустите приложение.
2.  Приложение автоматически обнаружит модели.
3.  Если модели найдены, в логах появится сообщение `Silero TTS initialized successfully`.
4.  Если модели отсутствуют, приложение будет использовать стандартный Android TTS (Google TTS).
