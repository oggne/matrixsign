# Модель Slovo для распознавания РЖЯ (Русский жестовый язык)

## Описание

Модель Slovo используется для распознавания жестов русского жестового языка (РЖЯ) в реальном времени.

## Установка модели

1. Скачайте модель `slovo_gestures.task` с HuggingFace:
   - URL: https://huggingface.co/hukenovs/slovo/resolve/main/slovo_gestures.task
   - Размер: ~50-100 МБ

2. Разместите файл в папке:
   ```
   app/src/main/assets/slovo_gestures.task
   ```

3. Пересоберите проект в Android Studio

## Использование

Модель автоматически загружается при выборе языка жестов "РЖЯ" в настройках приложения.

Если модель не найдена, приложение использует стандартную модель MediaPipe `gesture_recognizer.task` как fallback.

## Поддерживаемые жесты

Модель распознаёт более 1000 жестов РЖЯ, включая:
- Базовые жесты (привет, пока, спасибо, да, нет)
- Буквы алфавита
- Числа
- Бытовые фразы
- Эмоциональные жесты

Полный список жестов доступен в `rsl_dictionary.json`.

## Технические детали

- Формат: MediaPipe Task (.task)
- Размер: ~50-100 МБ
- Точность: >90% для базовых жестов
- Задержка: <100ms на современных устройствах

## Примечания

- Модель работает полностью оффлайн
- Требуется GPU для оптимальной производительности
- Поддерживается распознавание одной или двух рук одновременно
