# 🎓 Руководство по обучению моделей РЖЯ

В этом руководстве описано, как создать и обучить собственную модель для распознавания жестов Русского Жестового Языка (РЖЯ).

## 📋 Обзор процесса

1.  **Сбор данных:** Использование приложения для записи координат рук (landmarks) в CSV файл.
2.  **Обучение:** Запуск Python скрипта на компьютере для создания модели (`.tflite`).
3.  **Установка:** Копирование модели обратно в приложение.

---

## 📱 Шаг 1: Сбор данных в приложении

1.  Запустите приложение **MatrixSign**.
2.  Перейдите в раздел создания жестов (кнопка ✋).
3.  Введите название жеста (например, `Letter_A`).
4.  Нажмите кнопку **"Начать запись"** (или аналогичную, если реализован UI).
    *   *Примечание: В текущей версии нужно использовать функцию `saveLandmarksToCsv` в коде или через временный UI.*
5.  Показывайте жест перед камерой, слегка меняя ракурс и расстояние.
6.  Запишите 50-100 кадров для каждого жеста.
7.  Повторите для других жестов.
8.  Файл с данными будет сохранен в:
    `Android/data/com.matrixsign/files/datasets/rsl_data.csv`

---

## 📂 Шаг 1.5: Использование датасета Slovo (Опционально)

Если у вас есть скачанный датасет **Slovo** (видеофайлы), вы можете использовать его для создания мощной модели.

1.  Убедитесь, что у вас установлены библиотеки:
    ```bash
    pip install opencv-python mediapipe tqdm
    ```
2.  Запустите скрипт обработки (укажите путь к папке с датасетом):
    ```bash
    python process_slovo_dataset.py --dataset_path "C:\Users\Admin\Downloads\slovo"
    ```
    *   Скрипт просканирует все видео, найдет руки и сохранит координаты в `rsl_data.csv`.
    *   Это может занять время (от 10 минут до нескольких часов в зависимости от объема).

3.  После завершения переходите к **Шагу 2** (Обучение), используя полученный файл `rsl_data.csv`.

---

## 💻 Шаг 2: Обучение модели (Python)

1.  Скопируйте файл `rsl_data.csv` с телефона на компьютер в папку с проектом.
2.  Убедитесь, что у вас установлен Python и необходимые библиотеки:
    ```bash
    pip install tensorflow scikit-learn numpy
    ```
3.  Запустите скрипт обучения:
    ```bash
    python train_rsl_model.py
    ```
4.  Скрипт создаст два файла:
    *   `rsl_classifier.tflite` (сама модель)
    *   `rsl_labels.txt` (список жестов)

---

## 📲 Шаг 3: Установка модели в приложение

1.  Скопируйте созданные файлы (`rsl_classifier.tflite` и `rsl_labels.txt`) обратно на телефон в папку:
    `Android/data/com.matrixsign/files/`
2.  Перезапустите приложение.
3.  Теперь при показе жестов приложение будет отображать ваши кастомные метки!

## 🛠 Устранение неполадок

*   **Модель не работает:** Проверьте, что имена файлов точные (`rsl_classifier.tflite`).
*   **Низкая точность:** Запишите больше данных (200+ кадров на жест) в разных условиях освещения.
