# Как найти External Libraries в Android Studio

## 🔍 Способ 1: Через панель Project (самый простой)

### Шаги:

1. **В левой панели Android Studio** найдите вкладку **"Project"**
   - Если не видите — нажмите на вкладку слева (может быть "Android", "Packages" и т.д.)

2. **Вверху панели Project** найдите выпадающий список
   - Обычно там написано "Android" или "Project"
   - Нажмите на него

3. **Выберите "Project"** из списка
   - Это изменит вид отображения файлов

4. **Раскройте структуру:**
   ```
   MatrixSign (корень проекта)
   └── .gradle
   └── app
   └── External Libraries  ← ВОТ ОНА!
       ├── Android API 35 Platform
       ├── com.google.mediapipe:tasks-vision:0.10.14
       ├── androidx.camera:camera-core:1.3.4
       └── ... другие библиотеки
   ```

## 🔍 Способ 2: Через меню View

1. Нажмите **`View`** в верхнем меню
2. Выберите **`Tool Windows`** → **`Project`**
3. В панели Project выберите режим **"Project"** (не "Android")
4. Найдите **"External Libraries"** внизу списка

## 🔍 Способ 3: Альтернативная проверка (если не нашли)

### Через окно Build:

1. Внизу Android Studio откройте вкладку **"Build"**
2. После синхронизации там будет список загруженных библиотек
3. Ищите строки с `com.google.mediapipe`

### Через Gradle панель:

1. Справа в Android Studio найдите панель **"Gradle"**
   - Если не видите: `View` → `Tool Windows` → `Gradle`
2. Раскройте: `MatrixSign` → `app` → `Tasks` → `android`
3. Дважды кликните на **`dependencies`**
4. В окне Build появится список всех зависимостей

### Через терминал:

1. Внизу Android Studio откройте вкладку **"Terminal"**
2. Введите команду:
   ```bash
   ./gradlew :app:dependencies
   ```
3. Нажмите Enter
4. В выводе ищите `com.google.mediapipe`

## 🎯 Быстрая проверка без External Libraries

Если не можете найти External Libraries, используйте эти способы:

### Способ A: Проверка через синхронизацию

1. `File` → `Sync Project with Gradle Files`
2. Смотрите в окно **Build** (внизу)
3. Если видите:
   - ✅ `BUILD SUCCESSFUL` — зависимости загружены
   - ❌ `BUILD FAILED` — есть проблемы

### Способ B: Проверка через ошибки компиляции

1. Попробуйте скомпилировать проект: `Build` → `Make Project`
2. Если нет ошибок типа "Unresolved reference" — зависимости загружены ✅
3. Если есть ошибки — зависимости не загружены ❌

### Способ C: Проверка через код

1. Откройте файл `GestureRecognizerHelper.kt`
2. Найдите строку: `import com.google.mediapipe.tasks.vision.gesturerecognizer.*`
3. Если Android Studio не подчёркивает красным — зависимости загружены ✅
4. Если подчёркивает красным — зависимости не загружены ❌

## 💡 Полезные советы

1. **External Libraries появляется только после синхронизации**
   - Сначала синхронизируйте проект
   - Потом ищите External Libraries

2. **Может быть внизу списка**
   - Прокрутите список Project вниз
   - External Libraries обычно в самом низу

3. **Разные режимы отображения**
   - В режиме "Android" External Libraries может не показываться
   - Переключитесь на режим "Project"

## 🔧 Если всё равно не нашли

Не переживайте! External Libraries — это просто удобный способ просмотра. 

**Главное — проверить, что проект компилируется:**

1. `Build` → `Make Project`
2. Если нет ошибок — всё хорошо! ✅
3. Если есть ошибки — нужно исправить

## ✅ Альтернативный способ проверки

**Самый простой способ:**

1. Откройте любой файл с кодом (например, `GestureRecognizerHelper.kt`)
2. Посмотрите на импорты вверху файла
3. Если они не подчёркнуты красным — зависимости загружены! ✅

Пример правильных импортов (не должны быть красными):
```kotlin
import com.google.mediapipe.tasks.vision.gesturerecognizer.*
import com.google.mediapipe.tasks.vision.handlandmarker.*
```

Если эти строки красные — зависимости не загружены ❌
