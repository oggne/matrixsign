# Реализация экрана согласия на обработку биометрических данных

## ✅ Созданные файлы

### 1. ConsentManager.kt
- Управление согласием через SharedPreferences
- Методы: `hasConsent()`, `saveConsent()`, `revokeConsent()`
- При отзыве согласия удаляет все данные (SharedPreferences, Room DB, DataStore)

### 2. OnboardingConsentActivity.kt
- Экран согласия с полным текстом согласно 152-ФЗ и GDPR
- Обязательный чекбокс (не предзаполненный)
- Кнопки: "Политика конфиденциальности", "Продолжить", "Отказаться"
- Стиль Matrix: чёрный фон с зелёным шумом, зелёный текст #00FF41

### 3. PrivacyPolicyActivity.kt
- Полный текст политики конфиденциальности
- Прокручиваемый экран
- Готов к копированию текста

## 🔧 Обновлённые файлы

### 1. AndroidManifest.xml
- `OnboardingConsentActivity` теперь главная активность (MAIN + LAUNCHER)
- `MainActivity` экспортирован как `false` (запускается только изнутри)
- Добавлена `PrivacyPolicyActivity`

### 2. MainActivity.kt
- Проверка согласия при запуске
- Если согласие не дано → переход на `OnboardingConsentActivity`

### 3. DialogScreen.kt
- Добавлена кнопка "Отозвать согласие и удалить все данные" в настройках
- Диалог подтверждения отзыва согласия (`RevokeConsentDialog`)
- При отзыве → удаление всех данных → возврат на экран согласия

## 📋 Соответствие требованиям

### 152-ФЗ (Россия)
✅ Явное согласие на обработку биометрических данных (ст. 11)
✅ Информирование о целях обработки
✅ Возможность отзыва согласия
✅ Локальная обработка данных

### GDPR (Европа)
✅ Явное согласие (ст. 9 - биометрические данные)
✅ Право на удаление данных
✅ Прозрачность обработки
✅ Минимизация данных

## 🎨 Стиль экрана

- **Фон**: Чёрный с зелёным радиальным градиентом (эффект "шума")
- **Текст**: Зелёный #00FF41, JetBrains Mono / Roboto Mono Medium 20-22sp
- **Чекбокс**: Зелёный контур, минималистично
- **Кнопки**: Зелёный контур, активная только после установки чекбокса

## 📱 Логика работы

1. **Первый запуск**: `OnboardingConsentActivity` → экран согласия
2. **После согласия**: Сохранение в SharedPreferences → переход в `MainActivity`
3. **Последующие запуски**: Проверка согласия → если дано, сразу `MainActivity`
4. **Отзыв согласия**: Настройки → "Отозвать согласие" → удаление всех данных → возврат на экран согласия

## 🔒 Безопасность данных

- Все данные обрабатываются локально
- Никакие данные не передаются в интернет
- Видео и аудио удаляются сразу после обработки
- Кастомные жесты хранятся только локально
- При удалении приложения все данные удаляются автоматически

## 📝 Для Google Play Console
