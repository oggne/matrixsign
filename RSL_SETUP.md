# 🛠 Настройка Русского Жестового Языка (РЖЯ)

Внимание! Для работы распознавания РЖЯ требуется специальная модель, которая не включена в исходный код из-за большого размера.

## 📥 Шаг 1: Скачивание модели

Вам необходимо скачать файл `slovo_gestures.task`.

**Варианты скачивания:**
1.  **Прямая ссылка (HuggingFace):** [Скачать slovo_gestures.task](https://huggingface.co/hukenovs/slovo/resolve/main/slovo_gestures.task)
2.  **Альтернатива:** Если прямая ссылка не работает, ищите "slovo gestures mediapipe task" на HuggingFace.

## 📂 Шаг 2: Установка файла

1.  Скачанный файл `slovo_gestures.task` нужно поместить в папку `assets` вашего проекта.
2.  **Путь:** `app/src/main/assets/slovo_gestures.task`

Если папки `assets` нет, создайте её:
`app/src/main` -> `New` -> `Directory` -> `assets`

## ✅ Шаг 3: Проверка

1.  Пересоберите и запустите приложение.
2.  Зайдите в настройки (кнопка 🌐 или ⚙).
3.  Выберите "Русский жестовый язык (РЖЯ)".
4.  Если красное предупреждение "МОДЕЛЬ РЖЯ НЕ НАЙДЕНА" исчезло — всё настроено верно!

## ❓ Что делать, если модели нет?

Если вы не скачаете модель, приложение будет использовать стандартную модель (американский жестовый язык), которая может плохо понимать специфические жесты РЖЯ.
