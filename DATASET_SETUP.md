# 📦 Настройка датасета Slovo

Поскольку загрузка датасета не была завершена, мы подготовили скрипт для автоматического скачивания и распаковки.

## 1. Скачивание датасета

Мы создали скрипт `download_slovo.py`, который поддерживает **докачку** файлов. Если интернет пропадет, просто запустите скрипт снова, и он продолжит с того же места.

Запустите в терминале:

```bash
python download_slovo.py
```

*   **Размер:** ~16 ГБ
*   **Время:** Зависит от интернета (может занять несколько часов)
*   **Куда скачается:** папка `slovo_dataset` в корне проекта

## 2. Обработка датасета

После завершения скачивания и распаковки, запустите обработку видео для извлечения ключевых точек рук:

```bash
python process_slovo_dataset.py --dataset_path slovo_dataset
```

*   **Результат:** файл `rsl_data.csv`
*   **Время:** Зависит от мощности процессора

## 3. Обучение модели

Когда `rsl_data.csv` будет готов, обучите модель:

```bash
python train_rsl_model.py
```

Это создаст файл `rsl_classifier.tflite`, который можно использовать в приложении.
