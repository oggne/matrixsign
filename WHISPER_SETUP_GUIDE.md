# 🤫 Настройка Offline STT (Whisper)

Для работы распознавания речи без интернета необходимо скачать модель Whisper и поместить её в папку приложения.

## 📥 Что скачать

Вам понадобятся два файла:
1.  **Модель:** `whisper.tflite` (рекомендуется версия `tiny` или `base` для мобильных устройств).
2.  **Словарь:** `filters_vocab_gen.bin` (или `vocab.json`).

### Где найти:
Вы можете найти готовые TFLite модели Whisper на HuggingFace или GitHub.
Пример поиска: "whisper tflite android".

*Рекомендуемый источник:*
[HuggingFace: tflite-tflite/whisper-tiny](https://huggingface.co/tflite-tflite/whisper-tiny)

## 📂 Куда положить

Скопируйте скачанные файлы в папку приложения на телефоне:

`Android/data/com.matrixsign/files/`

Итоговая структура:
```
Android/data/com.matrixsign/files/
├── whisper.tflite
└── filters_vocab_gen.bin (или vocab.json)
```

## 🚀 Как проверить

1.  Перезапустите приложение.
2.  Если файлы найдены, вверху экрана появится желтая надпись: **"OFFLINE MODE (Whisper)"**.
3.  Отключите интернет (режим полета).
4.  Попробуйте что-нибудь сказать. Текст должен появиться на экране.

## ⚠️ Примечание
Модель `tiny` весит около **40-75 МБ**.
Модель `base` весит около **140 МБ** (точнее, но медленнее).
Для старых устройств лучше использовать `tiny`.
