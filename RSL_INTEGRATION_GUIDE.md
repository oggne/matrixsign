# 🤟 Интеграция Русского Жестового Языка (РЖЯ)

В этом руководстве описан процесс обучения и интеграции модели распознавания РЖЯ в приложение MatrixSign.

## 📋 Обзор процесса

1.  **Скачивание датасета Slovo** (видео с жестами).
2.  **Обработка данных** (извлечение ключевых точек рук с помощью MediaPipe).
3.  **Обучение модели** (создание TFLite модели).
4.  **Интеграция** (копирование модели в приложение).

---

## 🚀 Шаг 1: Скачивание датасета Slovo

Датасет Slovo содержит тысячи видео с жестами РЖЯ.

1.  Перейдите в репозиторий: [https://github.com/hukenovs/slovo](https://github.com/hukenovs/slovo)
2.  Скачайте датасет (обычно он разбит на части или доступен через облачное хранилище).
3.  Распакуйте архив в удобную папку на компьютере (например, `C:\SlovoDataset`).
    *   Структура должна быть примерно такой:
        ```
        SlovoDataset/
        ├── A/
        │   ├── video1.mp4
        │   └── ...
        ├── B/
        │   ├── ...
        └── ...
        ```
    *   Или если структура другая, убедитесь, что скрипт сможет найти видео. Скрипт `process_slovo_dataset.py` ожидает, что имя папки является меткой класса (буквой или словом).

---

## ⚙️ Шаг 2: Обработка данных

На этом этапе мы превратим гигабайты видео в компактный CSV файл с координатами рук.

1.  Откройте терминал в папке проекта (`C:\Users\Admin\Desktop\8`).
2.  Установите необходимые библиотеки Python (если еще не установлены):
    ```bash
    pip install opencv-python mediapipe tqdm
    ```
3.  Запустите скрипт обработки:
    ```bash
    python process_slovo_dataset.py --dataset_path "C:\Path\To\SlovoDataset" --output_csv rsl_data.csv
    ```
    *   Замените `"C:\Path\To\SlovoDataset"` на реальный путь к распакованному датасету.
    *   Процесс может занять длительное время (от 30 минут до нескольких часов) в зависимости от мощности ПК.

**Результат:** Файл `rsl_data.csv` в папке проекта.

---

## 🧠 Шаг 3: Обучение модели

Теперь обучим нейросеть на полученных данных.

1.  Установите TensorFlow и Scikit-learn:
    ```bash
    pip install tensorflow scikit-learn numpy
    ```
2.  Запустите скрипт обучения:
    ```bash
    python train_rsl_model.py
    ```

**Результат:** Два файла в папке проекта:
*   `rsl_classifier.tflite` (сама модель)
*   `rsl_labels.txt` (список жестов)

---

## 📲 Шаг 4: Интеграция в приложение

1.  Подключите Android устройство к компьютеру.
2.  Скопируйте файлы `rsl_classifier.tflite` и `rsl_labels.txt` на устройство в папку приложения:
    ```
    Android/data/com.matrixsign/files/
    ```
    *   Если папки нет, запустите приложение один раз, чтобы она создалась.
    *   Можно использовать проводник Windows или команду ADB:
        ```bash
        adb push rsl_classifier.tflite /sdcard/Android/data/com.matrixsign/files/
        adb push rsl_labels.txt /sdcard/Android/data/com.matrixsign/files/
        ```

3.  **Перезапустите приложение MatrixSign.**

## ✅ Проверка

1.  В приложении зайдите в настройки (кнопка 🌐 или ⚙).
2.  Убедитесь, что выбран "Русский жестовый язык (РЖЯ)".
3.  Покажите жест перед камерой.
4.  Если жест распознан, его название (или буква) появится на экране.

---

## 🛠 Устранение неполадок

*   **Скрипт не находит видео:** Проверьте структуру папок датасета. Скрипт ищет файлы `.mp4`, `.avi`, `.mov` во всех подпапках.
*   **Модель плохо распознает:**
    *   Попробуйте добавить больше данных.
    *   Убедитесь, что освещение хорошее.
    *   Попробуйте увеличить количество эпох обучения в `train_rsl_model.py` (параметр `epochs=50` -> `100`).
*   **Приложение вылетает:** Проверьте логи через Logcat в Android Studio. Возможно, файлы модели повреждены или не скопированы.
