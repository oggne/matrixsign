# Инструкция по скачиванию необходимых ресурсов

## 1. Silero TTS v5_ru модели

### Источник
- **Репозиторий:** https://github.com/snakers4/silero-models
- **Модели:** https://models.silero.ai/models/tts/ru/

### Необходимые файлы

1. **ru_v5.pt** (~150 МБ) - основная модель для русского языка
   - Скачать: https://models.silero.ai/models/tts/ru/ru_v5.pt
   - Или конвертировать в ONNX: `ru_v5.onnx`

2. **Голоса** (встроены в модель, но можно выбрать):
   - `kseniya` (женский, по умолчанию)
   - `eugene` (мужской, самый естественный)
   - `aidar` (мужской)
   - `baya` (женский)
   - `xenia` (женский)

### Размещение в проекте

```
app/src/main/assets/
└── silero/
    └── ru_v5.pt
```

### Альтернатива: ONNX Runtime версия

Если нужна более лёгкая версия для Android:
- Конвертировать `.pt` в `.onnx` используя скрипт из репозитория Silero
- Или использовать готовую ONNX версию (если доступна)

## 2. Slovo датасет (РЖЯ)

### Источник
- **Репозиторий:** https://github.com/hukenovs/slovo
- **Документация:** https://github.com/hukenovs/slovo/blob/main/README.md

### Необходимые файлы

1. **Ключевые точки жестов РЖЯ** (JSON/CSV)
   - Извлечь из датасета Slovo
   - Формат: координаты 21 точки руки для каждого жеста

2. **Модель классификации** (опционально)
   - TensorFlow Lite модель, если доступна
   - Или использовать MediaPipe Hand Landmarks + KNN классификатор

3. **Словарь жестов** (1000 самых частых жестов РЖЯ)
   - Список жестов с переводами
   - Формат: `жест -> текст`

### Размещение в проекте

```
app/src/main/assets/
└── slovo/
    ├── gestures.json (ключевые точки)
    ├── gestures_dictionary.json (словарь жестов)
    └── rsl_model.tflite (опционально, если есть)
```

### Альтернативный подход

Если датасет Slovo недоступен или слишком большой:
1. Использовать MediaPipe Hand Landmarks для извлечения признаков
2. Обучить простой KNN классификатор на собранных данных
3. Или использовать предобученные модели из других источников

## 3. ONNX Runtime (уже добавлен в build.gradle.kts)

Зависимость уже добавлена:
```kotlin
implementation("com.microsoft.onnxruntime:onnxruntime-android:1.18.0")
```

## 4. Проверка после скачивания

После размещения файлов проверьте структуру:

```
app/src/main/assets/
├── gesture_recognizer.task (уже есть)
├── hand_landmarker.task (уже есть)
├── silero/
│   └── ru_v5.pt
└── slovo/
    ├── gestures.json
    └── gestures_dictionary.json
```

## Примечания

- **Размер APK:** Silero модель (~150 МБ) значительно увеличит размер APK
- **Оптимизация:** Рассмотрите возможность загрузки модели при первом запуске
- **Оффлайн:** Все модели должны работать полностью оффлайн
- **Производительность:** Silero TTS на Snapdragon 8+ должен работать с latency <400 мс
