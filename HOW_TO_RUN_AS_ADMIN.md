# 🛡️ Как запустить скрипт от имени Администратора

Для создания символической ссылки (чтобы файл лежал на диске D:, но был виден на диске C:) требуются права администратора.

### Способ 1: Через меню Пуск (PowerShell или CMD)

1.  Нажмите кнопку **Пуск** (или клавишу `Win`).
2.  Введите в поиске **PowerShell** или **cmd**.
3.  Нажмите правой кнопкой мыши на найденное приложение и выберите **"Запуск от имени администратора"** (Run as Administrator).
4.  В открывшемся окне терминала перейдите в папку с проектом. Введите команду:
    ```powershell
    cd "c:\Users\Admin\Desktop\8"
    ```
5.  Запустите скрипт:
    ```powershell
    python setup_from_downloads.py
    ```

### Способ 2: Через Проводник (Explorer)

1.  Откройте папку `c:\Users\Admin\Desktop\8` в проводнике.
2.  Нажмите `Файл` -> `
` -> `Запустить от имени администратора`.
3.  В открывшемся окне введите:
    ```powershell
    python setup_from_downloads.py
    ```

### Что произойдет?
Скрипт скачает файл в `D:\slovo\slovo_gestures.task` и создаст "мостик" (ссылку) в папку `app/src/main/assets/`.
